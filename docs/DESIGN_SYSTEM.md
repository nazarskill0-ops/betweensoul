# Дизайн-система Calmi

Базові візуальні правила проєкту. Токени визначені в
[`src/app/globals.css`](../src/app/globals.css) (`@theme`) і доступні як
звичайні Tailwind-класи (`bg-sage`, `text-ink-muted`, `rounded-card` тощо).
Змінюй значення лише там — цей документ описує, коли який токен
використовувати, а не задає нові значення.

## Палітра

| Токен | Значення | Коли використовувати |
| --- | --- | --- |
| `sage` | `#7a9b76` | Основний бренд-колір: primary-кнопки, активний стан фільтрів/дропдаунів, посилання-акценти. |
| `sage-light` | `#e8efe6` | М'який фон для акцентних бейджів (методи терапії, кваліфікація) і активного стану кнопок-фільтрів. |
| `sand` | `#f5f1ea` | Фон сторінки (`body`). Базовий нейтральний фон, не для карток. |
| `sand-dark` | `#ede6db` | Обводки: картки, інпути, кнопки-фільтри у неактивному стані. Тонка нейтральна межа скрізь. |
| `rose` | `#c97a6a` | Другий акцент — для важливих/деструктивних дій: "Скинути", "Очистити", "Забронювати" (`accent`-варіант кнопки). Використовувати економно, не для рядового UI. |
| `ink` | `#2b332e` | Основний текст, заголовки. |
| `ink-muted` | `#6e6b62` | Другорядний текст: підписи, метадані (досвід, дата), плейсхолдери. |
| `card` | `#fefdfb` | Фон карток/поверхонь, коли потрібен відтінок, трохи світліший за чистий білий і тепліший за `sand`. |

Не додавай нових кольорів і не хардкодь hex — усе через ці токени.

## Типографіка

- `font-display` (Syne) — тільки для заголовків `h1`–`h3` і навмисних
  бренд-елементів (лого в хедері). Не використовувати для змішаних
  заголовків з великою часткою кирилиці — гарнітура нерівномірно підтримує
  кирилицю/латиницю.
- `font-sans` (Manrope) — усе інше: параграфи, лейбли, кнопки, бейджі. Це
  дефолтний шрифт `body`, окремий клас можна не вказувати.

## Форми

- `rounded-2xl` — картки, великі контейнери, панелі (модалки, дропдаун-панелі).
- `rounded-full` — кнопки, бейджі, чипи, інпути-пігулки (фільтри).
- `rounded-card` (16px, токен `--radius-card`) — де потрібен трохи менший
  радіус, ніж `rounded-2xl`, але більший за стандартні кнопки/бейджі.

## Spacing-принципи

- Між секціями сторінки (заголовок → фільтри → контент) — `gap-6`.
- Усередині картки, між логічними блоками (ім'я/досвід → методи/теми →
  ціна) — `gap-5`.
- Між елементами в межах однієї смислової групи (двома групами бейджів,
  назвою і підписом) — `gap-1.5`–`gap-2`.
- Між самими бейджами/чипами в ряду — `gap-2`–`gap-3` залежно від того,
  наскільки візуально важливою має виглядати група (важливіше → більший
  gap і більший розмір бейджа).
- Padding контейнерів (картки, панелі фільтрів) — `p-4`–`p-5`.
